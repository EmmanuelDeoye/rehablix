Install in 3 steps

Tap “Download for Android”

If Chrome asks “Do you want to download Rehablix.apk anyway?”, tap Download. That message appears for every app downloaded outside the Play Store.

Open the file

When it finishes, tap Open on the message at the bottom of the screen. Missed it? Pull down your notifications and tap Rehablix.apk, or open the Files / Downloads app.

Tap “Install”

The first time only, your phone asks for permission to install apps from Chrome:

For your security, your phone is not allowed to install unknown apps from this source.
CANCELSETTINGS

Tap Settings, switch on Allow from this source, then go back:

Allow from this source

Tap Install, then Open. Sign in with your Rehablix email (or Google) and everything you made on the web is there.

If you see “Google Play Protect” / “Unsafe app blocked”: this appears because the app didn't come from the Play Store. Tap More details, then Install anyway. Rehablix is signed by its maker, Rehabverve, and never asks for anything beyond the camera and microphone when you use those features.

Having trouble?

“App not installed” or “conflicts with an existing package”
You still have an older test version of Rehablix. Uninstall it first (press and hold the Rehablix icon, then Uninstall), then open the downloaded file again. Your account, chats and work are saved online, so nothing is lost.
I can't find the “Allow from this source” switch
  • Samsung: Settings → Apps → Chrome → Install unknown apps → Allowed.
  • Tecno / Infinix / itel: Settings → Apps → Special app access → Install unknown apps → Chrome → Allow.
  • Xiaomi / Redmi: Settings → Privacy protection → Special permissions → Install unknown apps → Chrome → Allow.
  • Others: search Settings for “unknown apps”, choose the browser you used, and allow it.
If you downloaded with another browser (Opera, Phoenix, a file manager), allow that app instead of Chrome.
The download is slow or stopped
The app is a one-time download (size shown under the button). On weak mobile data, try Wi-Fi, or tap Download again: it starts over safely. Updates later are the same size, and the app tells you when one is ready.
“There was a problem parsing the package”
The download didn't finish. Delete Rehablix.apk from Downloads and tap Download again. Your phone needs Android 8 or newer.
Not enough storage
Rehablix needs about 200 MB free to install. Clear some space (old videos, WhatsApp media), then tap the file again.
Is it safe to install apps from a website?
Only from makers you trust. This file comes straight from Rehablix's own servers and is signed by Rehabverve; Android checks that signature on every update, so nobody else can replace it. After installing you can switch “Allow from this source” off again; updates still work.
How do updates work?
When a new version is out, the app shows an Update button. It brings you back to this page; tap Download and Install. Your data stays.
