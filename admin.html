App & Versions

Android app versions, forced updates and the tester notice

Android version

The app compares its own version code with these numbers every time it opens. Below the minimum it must update before it can be used; below the latest it gets a gentle "update available" prompt.

Tester notice

For the test builds you share before launch. When this is ON, every copy that was NOT installed from the Play Store keeps asking its user (on every open, then every few hours) to uninstall it and install the official app. Play Store installs never see it.

How notifications work

AI Tasks are raised on the user's own device. Center Invitations are sent automatically when a center invites someone. Smart Reminders go out at most once every 3 days, only to people who have been away for 2 days or more. Users can switch each kind off in Settings.
